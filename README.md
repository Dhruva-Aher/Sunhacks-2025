# 🧠 SynapseOS

> Your intelligent productivity command center.

SynapseOS is a full-stack AI workspace that blends task management, scheduling awareness, and conversational intelligence into one unified dashboard.

It’s not just a to-do app.  
It’s a smart operational layer for your day.

---

## 🚀 What is SynapseOS?

SynapseOS is a React + Flask application powered by Google Gemini that acts as:

- 🧠 An AI assistant with conversation memory
- 📋 A task execution layer
- 📅 A daily workload analyzer
- ✉️ A smart communication interface
- 📊 A real-time productivity dashboard

It brings intelligence into everyday workflow actions.

---

## ⚡ Core Capabilities

### 🧠 AI Memory Engine
- Persistent conversation context per session
- Natural language interaction
- Action-aware responses

### ✉️ Intelligent Actions (Simulated)
- Send email via prompt
- Schedule events via prompt
- Function execution detection from conversation

### 📋 Task Control System
- Add, complete, delete tasks
- Priority tagging (High / Medium / Low)
- Live pending task counter

### 📅 Temporal Awareness
- Calculates daily meeting load
- Shows workload percentage
- Displays next available time slot
- Visual progress ring indicator

### 🖥 Command Dashboard
- Sidebar navigation
- AI Hub
- Task Manager
- Upcoming events panel
- Email compose interface
- Document generation UI
